# Agustin Santagada — Portfolio

Static site served by Vercel at agustinsantagada.com.

- `public/index.html` — the whole site (CSS + JS inline)
- `public/images/`, `public/media/` — project images and videos
- `public/assets/` — extra images and videos referenced by the project pages

No build step: Vercel serves `public/` as is (see `vercel.json`).
